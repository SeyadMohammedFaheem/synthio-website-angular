# Synthio — Smarter AI agents. Better conversations.

An ultra-modern, high-performance landing page and interactive platform showcase for **Synthio**, built with **Angular 22** and **Tailwind CSS**.

---

## ✨ Features

- **⚡ Modern Angular 22 Architecture**: Standalone components, reactive signals (`signal`, `computed`), template control flow (`@if`, `@for`).
- **📱 Responsive Mobile Experience**: Fully optimized viewports down to 320px with custom mobile navigation drawer, accordion submenus, and zero overflow.
- **🧭 Interactive Navigation**: Floating dynamic theme navbar (blue-to-white scroll transition) with two-column dropdown menus for Products, Solutions, Resources, and Company.
- **🎛️ Live Interactive Hero Dashboard**: Real-time simulated inbox console with customer sentiment, automated draft replies, SLA tracking, and profile details.
- **🎨 Bento Grid Showcase**: High-impact visuals highlighting agent intelligence, sub-200ms latency voice synthesis, and multi-channel orchestration.
- **🔄 Everything In One Place**: Interactive 4-tab product suite featuring Voice AI agents, Email automation, Conversation workflows, and Unified analytics with dynamic gradient backdrops.
- **🧩 Integrations Directory**: Filterable directory of 24+ enterprise integrations (CRM, Helpdesk, Automation, Storage).
- **💳 Transparent Pricing & FAQ**: Monthly/annual toggle with volume discounts and interactive accordions.

---

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v20+ recommended)
- npm or pnpm

### Installation
```bash
npm install
```

### Development Server
```bash
npm start
# or
npx ng serve --port 4200
```
Navigate to `http://localhost:4200/`. The app will automatically reload if you change any source files.

### Production Build
```bash
npm run build
```
The build artifacts will be stored in the `dist/synthio-website` directory.
